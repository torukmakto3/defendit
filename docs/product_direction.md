# Product direction (beta)

## Creator-first, stamp-and-send

The main surface is **creator-driven**:

1. Drag-and-drop a PDF / Excel model / DOCX / MD onto `/`
2. Click **Learn** (private) and/or **Defend**
3. On pass, download the **stamp + printable cover**, attach to the same deliverable, send via email/Slack/Docs

Receivers don’t need a new account or portal for the first beta. The verify link + hash drop is enough trust. Receiver-initiated “Request a defense” links stay for teams that want to *mandate* defenses.

## Later: receiver widgets

An embeddable button / widget for interview portals, LMS, PR checks, and submission workflows — after the creator loop and receipt are trusted. See MVP plan §1.1 integrations.

## Why this fits the thesis

Motivation comes from the credential (the stamp), not from “get smarter.” Creators own the artifact; sharing is optional and uses existing channels — Grammarly Authorship-style “user decides when to share.”
