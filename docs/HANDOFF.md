# Handoff

## DONE

- 2026-10-19: Interview reliability. Model JSON is schema-checked with one repair turn and a timeout (`LLM_TIMEOUT_MS`, default 45s). Saving the same Defend answer twice returns the stored progress instead of a 409, so a retry after a dropped response is safe. A different answer for a stored question is still refused. Finishing a defense that already has a receipt returns that receipt. The Defend page uses a phase machine (start, answer, save, grade, follow-up, error) with retry on a failed start and a failed grade. Learn ignores a second submit and a React strict-mode double start.
- 2026-10-19: Scoring redesign (`defend-it-rubric-v0.3`). Claim extraction builds a claim map (claim / assumption / number, plus figures) at temperature 0, and falls back to a local extractor. Questions are sampled from a fixed blueprint; the seed changes order, wording, and which claim fills a slot, not the mix. Each answer is scored on anchored 0–4 levels. Evidence has to be a quote from the answer. The receipt score is the difficulty-weighted median across graders. A holistic 0–100 from the model is ignored (a live defense on production had been receipted at 4/100 when the model answered on the 0–4 scale). If two graders are 2 or more levels apart, the session asks one follow-up instead of averaging, then takes the median and flags the receipt if they still disagree. `npm run calibrate` reports run-to-run variance and a cost estimate. `npm run soak` runs Learn and Defend on the three calibration fixtures.
- 2026-10-19: Calibration numbers (mock council, no live keys in this environment). Same answer, 8 reruns: stdev 0.00 on each fixture (investment memo 74, technical note 75, short essay 78 for a known-good answer; 25 for "I don't know"). Council members still differ by up to 25 points on their own scores; the receipt uses the median. Seeded simulation, 40 runs: known-good stdev 18 (range 16–75) before, stdev 1.6 (range 69–75) after; known-bad stdev 8.1 before, stdev 0 after. Cost for a ~2k-token document, 5 learn turns, 3 graders: before about $0.12 frontier / $0.005 open-weight (15.4k in + 5.1k out); after, with a follow-up on 15% of defenses, about $0.14 / $0.006 (18.1k in + 5.6k out); if every defense is graded twice, about $0.19 frontier. Voice minutes are not in that estimate.
