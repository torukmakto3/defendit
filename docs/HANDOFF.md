# Handoff

## DONE

- 2026-10-19: Interview reliability. Model JSON is schema-checked with one repair turn and a timeout (`LLM_TIMEOUT_MS`, default 45s). Saving the same Defend answer twice returns the stored progress instead of a 409, so a retry after a dropped response is safe. A different answer for a stored question is still refused. Finishing a defense that already has a receipt returns that receipt. The Defend page uses a phase machine (start, answer, save, grade, follow-up, error) with retry on a failed start and a failed grade. Learn ignores a second submit and a React strict-mode double start.
- 2026-10-19: Scoring redesign (`defend-it-rubric-v0.4`). Claim extraction builds a claim map (claim / assumption / number, plus figures) at temperature 0, and falls back to a local extractor. Questions are sampled from a fixed blueprint; the seed changes order, wording, and which claim fills a slot, not the mix. Each question cites the claim, quote, or figure it tests, is checked (grounded, unambiguous, answerable from the document) and rewritten once if that fails, and stores the cited source span. The creator's receipt shows that span; the public receipt does not. Each answer is scored on anchored 0–4 levels. Level 0 is no substantive engagement: a blank, "I don't know", a hedge, an off-topic reply, or a restatement of the question scores 0 on every dimension. Evidence has to be a quote from the answer. The receipt score is the difficulty-weighted median across graders. A holistic 0–100 from the model is ignored (a live defense on production had been receipted at 4/100 when the model answered on the 0–4 scale). If two graders are 2 or more levels apart, the session asks one follow-up instead of averaging, then takes the median and flags the receipt. The receipt is not held for a person. On a voice defense the follow-up is typed. `npm run calibrate` reports run-to-run variance and a cost estimate. `npm run soak` runs Learn and Defend on the three calibration fixtures.
- 2026-10-19: Calibration numbers (mock council, no live keys in this environment). Same answer, 8 reruns: stdev 0.00 on each fixture. Known-good: investment memo 74, technical note 75, short essay 78. Known-bad ("I guess it's fine.") 0. "I don't know." 0. Council members still differ by up to 25 points on a good answer; the receipt uses the median. Seeded simulation, 40 runs: known-good stdev 18 (range 16–75) before, stdev 1.6 (range 69–75) after; a weak-but-engaged answer stdev 8.1 before, stdev 0 (mean 19) after. Cost for a ~2k-token document, 5 learn turns, 3 graders, and a question rewrite on about a quarter of defenses: before $0.122 frontier / $0.005 open-weight (15.4k in + 5.1k out); after, with a follow-up on 15% of defenses, $0.140 / $0.006 (18.4k in + 5.7k out); if every defense is graded twice, $0.189 frontier. Voice minutes are not in that estimate.
